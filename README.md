# GlowFit AI — Frontend Final

GlowFit AI is a frontend-focused personal style, wardrobe, skincare and grooming recommendation project.

## Technically implemented
- Responsive single-page interface
- Four persistent themes
- User-controlled FitCheck inputs
- Browser-side outfit ranking/recommendation logic
- Style comparison with user photo upload (not fake virtual try-on)
- Digital wardrobe with localStorage persistence
- Dress Me Today using stored wardrobe items
- Skin type + undertone profile
- Dynamic color palette
- Rule-based skincare routine builder
- Home/lifestyle vs commercial-care sections
- Local demo product catalog with profile/budget filtering
- Side-by-side product comparison
- Grooming reference suggestions
- Progress dashboard based on local app data
- Rule-based interactive GlowFit Stylist
- Profile/privacy controls

## Intentionally future scope
- Generative Virtual Try-On AI
- LLM-based stylist
- Computer vision skin/clothing analysis
- Backend/database/authentication
- Live shopping prices and stock

This separation is intentional so the project remains technically honest and appropriate for a frontend-development viva.

## Run
Open `index.html` directly or deploy the repository root with GitHub Pages.
